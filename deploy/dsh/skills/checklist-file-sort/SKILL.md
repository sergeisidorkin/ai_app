# checklist-file-sort

Один вызов обрабатывает один встроенный `<chunk-json>` из сообщения пользователя.

## Ограничения

- Работай только внутри текущего workspace.
- Используй только встроенный chunk JSON. В нём уже есть полный список комплектов и допустимых пунктов `dest`.
- Не открывай chunk-файл: его содержимое уже передано в сообщении.
- Не вызывай `find`, `ls` и другие команды обхода файлов.
- Не открывай бинарные файлы, не копируй и не перемещай данные.
- Не добавляй комплекты, которых нет в `kits`.
- Верни строки только для комплектов, относящихся к выбранному разделу; пропущенные комплекты считаются нерелевантными.
- Для каждой возвращённой строки сохрани `id` без изменений.
- `dest` должен указывать на один из `dest_items[].folder` внутри `section.folder`.

## Классификация

Сопоставляй `kit_path`, `samples`, `text_excerpts` и `extensions` с
`request_name` и `quote`.
Учитывай профессиональные сокращения, русские/английские синонимы и общий
смысл группы имён. Несколько согласованных имён файлов могут дать высокую
уверенность без открытия архивов и бинарных файлов.
Положение комплекта вне одноимённой папки выбранного раздела не является
основанием для `ignore`: сравни все переданные комплекты и не предпочитай
слабое совпадение внутри папки более сильному совпадению вне неё.

- Однозначное совпадение с конкретным пунктом: `confidence: "высокая"`, `action: "move"`.
- Есть наиболее вероятный пункт, но данных мало: `confidence: "средняя"` или `"низкая"`, `action: "review"`.
- Пункт не определён: `dest` равен папке раздела, `name` и `quote` пустые, `action: "review"`.
- Комплект не относится к выбранному разделу: не включай его в ответ.
- Не выдумывай `name` и `quote`: копируй их из выбранного `dest_items`.

## Ответ

Сразу верни один компактный JSON-массив в fenced-блоке и остановись.
Каждый объект содержит только `id`, `dest`, `confidence`, `action`;
остальные поля сервер восстановит из входа:

```json
[
  {
    "id": "k-0123456789ab",
    "dest": "dest/06 LGL Право/LGL-01 Лицензии на недра",
    "confidence": "высокая",
    "action": "move"
  }
]
```
