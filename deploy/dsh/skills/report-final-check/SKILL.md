# report-final-check

Один вызов обрабатывает ровно один DOCX, указанный в сообщении пользователя.
Это file-in/file-out задача: обязательный результат — DOCX в указанном пути
`output/`, а не JSON в ответе.

## Ограничения

- Работай только внутри текущего workspace.
- Не меняй основной текст, стили, таблицы, изображения, колонтитулы и структуру
  исходного документа.
- Не пересказывай и не переписывай отчёт.
- Добавляй только комментарии Microsoft Word к фрагментам с достоверной
  несогласованностью падежей.
- Не отмечай стилистические предпочтения, спорные варианты управления,
  опечатки другого типа и формулировки, которые грамматически допустимы.
- Если уверенности недостаточно, не добавляй замечание.
- Не открывай и не обрабатывай другие файлы.

## Порядок работы

1. Возьми пути входа и результата из сообщения пользователя.
2. Извлеки текст командой:

```bash
python3 "$DSH_HOME/skills/report-final-check/scripts/docx_comments.py" \
  extract "input/ИМЯ.docx" "work/report.txt"
```

3. Прочитай `work/report.txt`. Проверь согласование падежей:
   - определение с существительным;
   - причастный оборот с определяемым словом;
   - однородные зависимые слова;
   - управление предлогов и глаголов;
   - местоимение и слово, к которому оно относится;
   - числительное и существительное.
4. Для каждого достоверного нарушения создай запись в `work/findings.json`.
   `quote` должен быть коротким дословным фрагментом из `report.txt`, но
   достаточным для точной привязки комментария. Если одинаковый фрагмент
   встречается несколько раз, добавь `occurrence` с номером вхождения,
   начиная с 1.
5. В `message` обязательно укажи:
   - что именно не согласовано;
   - требуемый падеж и почему он требуется;
   - корректный вариант фрагмента.
6. Если нарушений нет, запиши в `work/findings.json` пустой массив `[]`.
7. Создай итоговый DOCX:

```bash
python3 "$DSH_HOME/skills/report-final-check/scripts/docx_comments.py" \
  annotate "input/ИМЯ.docx" "output/ИМЯ.docx" "work/findings.json"
```

Формат рабочего JSON:

```json
[
  {
    "quote": "согласно утвержденного графика",
    "message": "Нарушено управление: предлог «согласно» требует дательного падежа. Корректно: «согласно утверждённому графику».",
    "author": "report-final-check"
  }
]
```

После создания проверь, что указанный файл в `output/` существует и не пуст.
В финальном ответе напиши только краткое подтверждение создания файла и
количество добавленных комментариев.
